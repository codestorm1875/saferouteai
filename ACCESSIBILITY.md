# Accessibility Statement ♿

SafeRouteAI is committed to digital inclusion. We strive to meet **WCAG 2.1 Level AA** standards.

## Key Features

### 1. Visual Accessibility
- **High Contrast Mode:** The "Cyberpunk" theme naturally uses high-contrast neon on dark backgrounds, aiding users with low vision.
- **Color Blindness Support:** Heatmap colors (Red/Green) are supplemented with icons and text labels (e.g., "Safe", "Danger") so color is not the only indicator.
- **Scalable Text:** All text respects system font size settings.

### 2. Screen Reader Compatibility
- **Semantic HTML:** Proper use of `<main>`, `<nav>`, `<button>`, and headings.
- **ARIA Labels:** Interactive elements like the map and SOS button have descriptive `aria-label` attributes (e.g., "Report Incident Button").
- **Alt Text:** All images and icons have meaningful alternative text.

### 3. Motor Accessibility
- **Large Touch Targets:** All buttons are at least 44x44 pixels.
- **Keyboard Navigation:** Full support for tab navigation on web.
- **Voice Control:** Compatible with standard voice control assistants.

## Ongoing Improvements
- **Audit:** We conduct monthly accessibility audits using Lighthouse and manual testing.
- **Feedback:** We actively solicit feedback from users with disabilities to improve the experience.
