# SafeRouteAI Quickstart Guide 🚀

## ⏱️ 5-Minute Setup

### Prerequisites
- Python 3.8+
- Node.js 16+
- npm or yarn

### 1. Backend Setup
```bash
cd backend
pip install -r requirements.txt
python main.py
```
*Server starts at `http://localhost:8000`*

### 2. Frontend Setup
```bash
cd app
npm install
npm run dev
```
*App opens at `http://localhost:3000`*

## 🎬 Demo Script (3 Minutes)

**Goal:** Demonstrate how SafeRouteAI keeps Lagosians safe.

### Scene 1: The "Safe" View (0:00 - 0:45)
- **Action:** Open the app to the **Home Screen**.
- **Narration:** "Welcome to SafeRouteAI. Immediately, you see a real-time safety heatmap of Lagos. Green zones are safe, red zones are high-risk. This data is updated every 10 seconds using our multi-factor scoring engine."
- **Highlight:** Point out a "Green" zone (e.g., Victoria Island) and a "Red" zone.

### Scene 2: Planning a Journey (0:45 - 1:30)
- **Action:** Tap **"Safe Route"**. Enter "Ikeja City Mall" to "Landmark Beach".
- **Narration:** "I need to get to the beach. Standard maps give me the fastest route, but SafeRouteAI gives me the *safest* route. Notice how we avoid the high-incident area in Surulere, adding only 5 minutes to the trip but increasing the safety score by 40%."

### Scene 3: Community Power (1:30 - 2:15)
- **Action:** Tap **"Report"**. Select "Robbery", Medium Severity.
- **Narration:** "Safety is a community effort. I just witnessed an incident. With two taps, I report it. It's instantly verified and updates the heatmap for everyone else."
- **Action:** Go to **"Feed"** to show the new report.

### Scene 4: Emergency (2:15 - 3:00)
- **Action:** Tap the **"Emergency"** tab.
- **Narration:** "In a crisis, every second counts. Here we have one-tap access to Police (112/767), an SOS flasher, and instant location sharing with trusted contacts."

**Closing:** "SafeRouteAI: Navigating a safer Lagos, together."
