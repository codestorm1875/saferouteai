# Design System: Cyberpunk Lagos 🎨

A futuristic, high-contrast visual language reflecting the vibrant energy and chaotic order of Lagos.

## 1. Color Palette

| Color Name | Hex Code | Usage |
|------------|----------|-------|
| **Void Black** | `#0a0a0a` | Main Background |
| **Neon Green** | `#00ff9d` | Safe Zones, Success Actions |
| **Warning Yellow** | `#ffd700` | Moderate Zones, Alerts |
| **Danger Red** | `#ff0055` | Danger Zones, SOS, Errors |
| **Cyber Blue** | `#00d4ff` | Primary Buttons, Links |
| **Glass Grey** | `rgba(255,255,255,0.1)` | Cards, Overlays (Glassmorphism) |

## 2. Typography
- **Font Family:** `Inter`, sans-serif.
- **Headings:** Bold, Uppercase, Tracking +1px.
- **Body:** Clean, legible at small sizes.

## 3. UI Components

### Glass Cards
- **Background:** Semi-transparent black with blur (`backdrop-filter: blur(10px)`).
- **Border:** Thin, 1px solid white/10.
- **Shadow:** Soft neon glow on hover.

### Map Styling
- **Base:** Dark mode custom tiles.
- **Overlays:** Glowing geometric shapes for safety zones.
- **Markers:** Pulsing animations for active incidents.

## 4. Design Philosophy
- **"Data is Light":** Information should glow against the dark background.
- **Minimalism:** Remove clutter to focus on the map and safety data.
- **Urgency:** Emergency features are visually distinct and demand attention.
